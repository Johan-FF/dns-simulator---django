# Internationalization (i18n)

## URL language prefix

Public routes use Django `i18n_patterns` (see `ChibchaWeb/urls.py`). Switch language via `/i18n/setlang/` or the language selector component.

## Extract and compile messages

```bash
conda activate p
python manage.py makemessages -l en -l pt
python scripts/translate_po.py --all
python manage.py compilemessages
```

## Translation helper script

`scripts/translate_po.py` fills empty `msgstr` entries using a small glossary and English passthrough. Root `traducir_po_v2.py` is gitignored; use the script under `scripts/` instead.

## Django 5 note

`USE_L10N` was removed in Django 5; formatting is controlled via `FORMAT_MODULE_PATH` if needed. This project uses `USE_I18N` and `USE_TZ` only.
